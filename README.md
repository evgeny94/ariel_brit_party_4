# Ariel's Brit Party — Gallery Part 4 of 4

A photo gallery from Ariel Tzur Musatov's brit party (January 2025), with a Hebrew UI. Each photo has a one-click download of the full-resolution original.

**Live:** https://evgeny94.github.io/ariel_brit_party_4/

The gallery is split across four GitHub Pages sites because the full set of 349 photos is too large for one site:

| Part | Photos | Link |
|---|---|---|
| 1 | 1–87 | https://evgeny94.github.io/ariel_brit_party_1/ |
| 2 | 88–175 | https://evgeny94.github.io/ariel_brit_party_2/ |
| 3 | 176–263 | https://evgeny94.github.io/ariel_brit_party_3/ |
| 4 | 264–349 | https://evgeny94.github.io/ariel_brit_party_4/ |

## Run locally

```bash
python -m http.server 8000
```
Then open http://localhost:8000.

## Deploy

GitHub Pages serves the `main` branch, so pushing to `main` publishes the site. Changes to the layout or navigation need to be made in all four repos.

Built with plain HTML, CSS and JavaScript (no build step).
